# Samples

| Folder | Contents |
|--------|----------|
| `placement/` | Geometry test pack (position and size vs the dash). See `placement/README.md`. |
| `honor/` | Customize honor/ignore probes (hidden keys, scale on). See `honor/README.md`. |

12.3" and 6.86" files are the same 1280×480 canvas.

**Load** an INI from `placement/` or `honor/`. The editor resolves `PlacementGray.jpg` from that folder's `internal/images/`.

**Do not Save** honor or placement files from the editor.
